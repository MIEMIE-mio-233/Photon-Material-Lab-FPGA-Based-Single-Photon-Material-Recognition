# 直方图特征案例

距离和材料均影响回波峰位，Fe测距曲线在其他材料上出现偏差。主要模型比较固定15 cm，光照和轮次作为辅助记录，标签修正依据实际采集条件确认。

第9维为回波峰减模型基线。基线优先取训练折内15 cm Fe峰位中位数，缺少时用零基线并记录绝对峰位模式。其余八维描述面积与峰高比、核心及尾沿比例、宽度和峰高面积比。

CNN从后峰附近2048 bin按8点求和得到256点，面积归一化后，经卷积、ReLU和池化形成波形表示，与标准化九维拼接。
