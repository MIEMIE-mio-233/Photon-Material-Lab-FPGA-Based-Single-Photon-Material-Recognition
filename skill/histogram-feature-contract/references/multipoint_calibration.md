# 多点测距与分类基线

Fe校准曲线用于塑料和木材时存在材料相关偏差，因此分类基线、距离曲线与类别模型分别保存和核验。

同一标准靶与稳定光路下记录已知距离。每点10个完整直方图，取峰位中位数；至少三点建立拟合。各点保留原始帧、配置及启动标识，点数和重复次数按目标系统稳定性选择。

采集前核对参考源、幅值、阈值、门控和bin单位。删除参与拟合的点后使曲线失效，重新拟合后启用。曲线绑定采集配置，模型切换沿用同一有效曲线。

校准残差与未参与拟合的位置、材料误差分别评价。中位数减少随机波动，材料响应、阈值时延、出光延迟和线缆偏置通过相应实验分析。

实现见[校准存储](../../../src/ps/live_ranging.py)，[便携回归](../../../src/ps/tests/test_live_range_portable.py)采用合成双峰验证三点拟合及单点删除失效。
