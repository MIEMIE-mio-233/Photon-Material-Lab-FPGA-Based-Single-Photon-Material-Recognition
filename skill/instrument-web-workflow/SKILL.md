# 仪器网页的异步任务与显示

分别定义请求受理、模型就绪、图表完成及网页前端显示事件，按相应起止点计时。

## 模型与图表

模型参数、报告和轻量快照校验归档后，发布模型就绪状态。PNG按版本、图类及类别等内容键缓存，使用有界队列和有限绘图进程。临时文件原子发布，绘图失败局限于对应图表。删除版本前终止相关任务并关闭句柄。

首次绘图、缓存读取和网页前端解码分别测量；图表使用版本快照生成，参数训练与绘图调用独立。

## 异步响应

请求携带数据、模型、视图身份和递增序号，响应提交时重新核对。离页时取消前端等待，后台任务按独立取消协议处理。[请求门控样例](scripts/request_gate.js)提供过期响应过滤，可与网络取消及缓存组合使用。

历史回放采用当前帧ID显示确认和有界超时推进，断开客户端后按超时继续。真实采集依据完整帧状态推进，多客户端确认条件由应用明确约定。

## 选择与对比

搜索过滤列表并保留勾选集合，分别提供追加筛选结果、仅选筛选结果与清空操作。空结果清除旧显示，选择统计覆盖全部勾选。

模型浏览、启用、删除及训练分别维护状态，冲突操作在任务期间锁定。多帧图保持单位和坐标可比；峰对齐及归一化由显式选项控制。布局切换复用已有结果。

桌面与窄屏检查筛选、勾选、版本、过期响应、空列表和重复识别。当前案例及测试见[验证记录](references/current_case.md)。
