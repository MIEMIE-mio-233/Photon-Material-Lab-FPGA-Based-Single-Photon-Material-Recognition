# 周期输出控制契约

依据外设行为确定有效沿、有效电平及停止状态，再定义相位和有效时长字段。

## 时间窗口

相位表示周期内位置，时长表示有效区间长度。统一时钟步长与舍入，回读实际整数拍。跨周期窗口按半开区间拆分。

[validate_windows.py](scripts/validate_windows.py)校验0≤相位<周期、1≤时长<周期，返回有效区间。支持PWM和触发等周期配置。

```bash
python scripts/validate_windows.py references/pwm_window.json
```

示例为低有效窗口，每周期区间为[0,20)和[80,100)拍，关闭逻辑电平为1。占满周期、负相位及多周期延迟需按目标RTL另定义契约。

终点计算加宽以容纳相位与时长之和，用比较及加减实现两段窗口。明确首次启动行为，当前案例等待首个完整窗口。

## 参数提交与停止

多字段在提交至应答期间保持稳定，于约定边界整组生效。网页依据回读显示pending、error或已生效。运行中互锁与修改条件沿用实际硬件协议。

采集停止和持续输出停止分别控制。关闭后每路维持各自无效电平；DAC原始码、正向码、数字接口电压及模拟幅值分别定义。码值转换只在约定接口执行一次，模拟电压结合量程与负载测量。

字段或有效电平语义改变时升级协议及客户端schema，加载前检查兼容性。数字区间、软件互锁和物理响应分别验证，见[案例](references/current_case.md)。
