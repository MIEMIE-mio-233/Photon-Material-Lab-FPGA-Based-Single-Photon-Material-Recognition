接口与参数说明

DAC1模拟输出接激光触发，DAC2接接收门控；前端测量通道的LVDS正负端接C1/B1（J1-36/34），参考通道接B3/A3（J1-32/30）。选择内部参考即可在FPGA内回接。参考源与电平码值需在停止采集、关闭输出后修改。

正向码范围0～1023，数值越大，输出电压越高。名义±5 V量程下，511约为0 V；1023对应模块当前可输出的最高电压（不固定为5 V）；实际电压取决于电位器和负载，以示波器实测为准。网页已补偿模块反相。关闭持续输出时，DAC1保持低电平，DAC2保持高电平以关闭探测。

探测窗口下降沿开启、上升沿关闭。默认相位9000 ns、时长2000 ns，在100 kHz下跨至下一周期1000 ns。激光参数描述电触发信号，不代表实际出光时刻；设置相位只调整周期位置，不表示启动后额外等待多个周期。

前端比较阈值设置TLV5618前端DAC产生的比较门限，范围0～1.000 V，按0.002 V就近量化；不改变激光触发、接收门控波形的高低电平。A/B与前端模拟通道的对应关系以实际接线为准。显示值为完成串行发送的设置值，不是模拟电压实测值。
